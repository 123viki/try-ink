# Try Ink

Site de tattoos temporárias Try Ink. Os ficheiros principais são simples de editar:

- `index.html` — textos, secções e links
- `styles.css` — cores, tamanhos e aspeto visual
- `script.js` — carrinho e interações

## Fotos reais das tattoos

Quando tiverem as fotografias finais, coloquem-nas numa pasta chamada `assets/tattoos/` e enviem os nomes dos ficheiros. O catálogo tem 31 espaços: os três primeiros são exemplos e os restantes aparecem como “Novo design”, prontos para receber as vossas fotos, nomes e preços. Por exemplo:

```text
assets/tattoos/lost-in-thought.jpg
assets/tattoos/moon-phase.jpg
assets/tattoos/flora-08.jpg
```

Depois as imagens de apresentação podem ser substituídas pelas fotos reais no site.

## Redes sociais e suporte

No rodapé existem links prontos para Instagram, TikTok e suporte. Quando tiverem os endereços, substituam os `href="#"` no `index.html` por exemplo:

```html
<a href="https://instagram.com/o_vosso_utilizador">Instagram</a>
<a href="https://tiktok.com/@o_vosso_utilizador">TikTok</a>
<a href="mailto:tryink.support@gmail.com">Suporte</a>
```
